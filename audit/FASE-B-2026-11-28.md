# Fase B — Email-gate CV lengkap (2026-11-28)

## Status
SIAP DEPLOY, **menunggu 4 kredensial dari Yunar** untuk mengaktifkan form.
Saat ini produksi berjalan dalam mode **mailto** (sesuai PRD A3) — tidak ada
jalur yang diam-diam terbuka dan tidak ada form yang pasti gagal.

## Yang sudah dibangun dan terbukti

### Fungsi serverless (Cloudflare Pages Functions)
- `functions/api/request-cv.js` — POST: validasi email, verifikasi Turnstile,
  rate-limit (1/email/hari, 50/hari global), tanda tangan token HMAC, kirim
  email tautan via Resend, notifikasi Telegram, tulis ke KV.
- `functions/api/download-cv.js` — GET: verifikasi token, batas 3 unduhan
  (KV), footer "Untuk: email | tanggal" di setiap halaman via pdf-lib,
  header `noindex` + `no-store` + `attachment`.
- `docs/_routes.json` — hanya `/api/*` yang menjalankan Functions; aset statis
  tetap gratis dan tidak dihitung kuota.

### Bukti runtime (bukan unit test)
Dijalankan di `wrangler pages dev` (runtime Cloudflare lokal, KV nyata):

```
GET  /api/request-cv                  -> 405
POST email tidak valid                -> 400 {"error":"email tidak valid"}
POST Turnstile palsu                  -> 403 {"error":"verifikasi manusia gagal"}
GET  /api/download-cv (tanpa token)   -> 400
GET  /api/download-cv (token cacat)   -> 403
GET  /api/download-cv (kedaluwarsa)   -> 403
GET  /api/download-cv  (1,2,3)        -> 200, 200, 200
GET  /api/download-cv  (4)            -> 429
```

Header respons unduhan yang terverifikasi:
```
Content-Type: application/pdf
Cache-Control: no-store, private
Content-Disposition: attachment; filename="Yunar-Prawira-CV.pdf"
X-Robots-Tag: noindex, nofollow, noarchive
```

Footer terbukti TERLIHAT saat PDF dirender (bukan hanya ada di bytes):
```
$ pdftotext /tmp/dl1.pdf - | grep Untuk
Untuk: rekruter@perusahaan.com | 28 Nov 2026
Untuk: rekruter@perusahaan.com | 28 Nov 2026      <- kedua halaman
```

### Uji terotomatis
- `node audit/test-functions.mjs` → **50/50 lolos** (deterministik, dijalankan 2x)
- `python3 audit/test-build-cv.py` → **25/25 lolos**

## Dua kegagalan nyata yang tertangkap dan diperbaiki

1. **Footer tidak terlihat meski bytes-nya ada.** Versi pertama menyisipkan
   operator teks ke content stream PDF. `grep` menemukan teksnya di file, tes
   lolos — tapi `pdftotext` kosong karena stream itu terkompresi Flate.
   Diperbaiki memakai pdf-lib. Tes sekarang mewajibkan bukti render.

2. **Token cacat menjatuhkan Worker.** `atob()` melempar DOMException pada
   base64 tidak valid, sehingga `?t=!!!` menghasilkan 500, bukan penolakan.
   Diperbaiki dengan penanganan eksplisit. Ini kelas bug yang membuat endpoint
   publik mudah dijadikan vektor DoS.

## Bentuk produksi hari ini
`https://yunarprawira.pages.dev` — statis 200 di semua rute, Functions aktif:
```
GET  /api/request-cv        -> 405
POST email invalid          -> 400
GET  /api/download-cv       -> 400
```

`/cv/` merender **mailto-only** karena `TURNSTILE_SITEKEY` masih placeholder.
Form lengkap hanya muncul kalau sitekey asli diberikan saat build:

```
$ python3 build_cv.py
docs/cv/index.html ditulis (13 KB, gate=mailto)
$ TURNSTILE_SITEKEY="0x4AAAAAAA_REALKEY123" python3 build_cv.py
docs/cv/index.html ditulis (14 KB, gate=form)
```

## Keputusan yang perlu dijawab
1. **Hosting situs utama.** Fase B menuntut Functions; situs utama masih di
   GitHub Pages. Fungsi sudah jalan di `yunarprawira.pages.dev`, tapi supaya
   `/api/*` satu domain dengan situs, `www.yunarprawira.com` harus pindah ke
   Cloudflare Pages. Belum aku lakukan — itu mengubah DNS produksi dan perlu
   persetujuanmu.
2. **Masa simpan email** (PRD minta ditentukan). Usulku: 12 bulan, lalu hapus;
   KV rate-limit sudah auto-expire 24 jam jadi tidak ada data permanen di sana.
3. **Follow-up hari ke-3**: PRD minta draf dikirim hanya setelah disetujui.
   Belum dibangun — butuh cron + persetujuan per email.
